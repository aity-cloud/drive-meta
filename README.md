# aity-cloud/drive/meta

Meta repo for the Aity Drive Clients subgroup: vocabulary (`CONTEXT.md`),
decisions (`docs/adr/`), the v1 spec (`specs/`), the maintenance loop
(`docs/maintenance.md`), the Renovate configuration that watches the three
Factories' Pins, and the brand master the Factories derive their assets
from (`brand/`).

The Factories are the sibling repos `android`, `ios` and `desktop`; the
private `certificates` repo is fastlane match's store.
